# Reflection

## Structure and architecture

Studio lives under `src/app/studio/` and `src/lib/studio/`, with shared infra in `src/lib/` and Gemini in `src/lib/gemini/`, so it can plug into the real Content OS later. A pure `composePrompt` function merges Goldfizh vision, versioned brand profiles, and validated user input; every generation stores that prompt plus layer IDs for replay.
The actual image generation is tied to my own gemini api key, which is on a free tier, meaning it has no images remaining to generate. I purposely left out the huge error it throws out when you try to generate an image, just to demonstrate the api call is working correctly.
The base prompt was also generated by AI, in a real world environment, i would generate it with AI but in a more serious way. This prompt was not thought out and reviewed, i just left the first thing it invented for time sake.
I have added a free way of generating images, through pollination. deployed website has my own API key, which can probably handle one or two images before running out of free credits. It is also explained how to get your own API key if needed/wanted.

## Risks at higher volume

Gemini rate limits and 10–30s latency per image will bottleneck synchronous Server Actions; production needs a job queue, webhooks or Realtime for status, and per-tenant budgets. Storage and signed-URL traffic grow linearly with generations; reference image downloads should be cached per brand version. Costs scale with resolution (`2K` default) and reference image count.

## With more time

Real Supabase Auth with RLS via user JWT, UI for brand knowledge uploads, async generation workers, multi-turn edits on top of `generateContent`, and Vertex AI.

## Where AI was deliberately not used

I used AI for the studio UI. The screen had to match a supplied frame, and that work is mostly layout and styling, so it was the right place to save time. I did not use AI for the Gemini connection, the prompt compiler, or the generation flow around them. I let AI generate the base styles, colors, formats and even brand guidelines/visions. Every piece of data that is hardcoded/scaffolded when it should be dynamic in an actual project, have been generated by AI and reviewed by me.
Project structure, meaning code organization/folders, were also initially drafted by AI, being later reorganized by me and my standards. Also some of the files created by AI were either overengineered, or simply complicating a simple task, like separating a single call into 3 different files.
